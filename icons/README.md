Lege dein App-Icon in diesen Ordner.

Empfohlene Dateien:
- `icon.ico` -> wird für Installer und EXE-Icon verwendet (Windows)
- `icon.png` -> wird in der laufenden App als Fenster-Icon verwendet (Fallback)

Hinweise:
- Für den Installer ist auf Windows eine `.ico`-Datei nötig.
- Wenn `icon.ico` fehlt, nutzt der Build ggf. ein Standard-Icon.
