Anleitung

Installation

  1. Installer herunterladen

    Nutze den Windows-x64-Installer aus dem GitHub Release. Ältere Releases tragen noch den Dateinamen X-Client.

  2. Öffnen & installieren

    Öffne die EXE-Datei. Der One-Click-Installer richtet den Launcher für dein Windows-Benutzerkonto ein.

  3. Anmelden & starten

    Starte X-Launcher, melde dich über Microsoft/Xbox an und wähle dein Fabric-Profil. Für lokale Tests gibt es den Offline-Modus.

FAQ

Häufige Fragen

Gibt es Builds für macOS oder Linux?

Die aktuelle Build-Konfiguration liefert Windows-x64-Installer und portable Windows-Builds. Andere Betriebssysteme werden hier nicht als unterstützt angeboten.

Wie funktionieren Updates?

Die installierte Version prüft GitHub Releases über electron-updater. Portable Builds musst du manuell aktualisieren.

Kann ich offline spielen?

Offline-Accounts dienen lokalen Tests. Multiplayer ist nur auf Offline-Mode-Servern möglich. Erste Downloads und die Microsoft-Anmeldung benötigen Internet.

Wo melde ich einen Fehler?

Erstelle ein Issue auf GitHub. Beschreibe deine Launcher-Version, Minecraft-Version und die Schritte, mit denen der Fehler auftritt. Teile keine Zugangsdaten oder Tokens.
