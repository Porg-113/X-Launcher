Alles in einem Client

Mehr spielen.
Weniger verwalten.

X Client verbindet deine Minecraft-Versionen, Mods, Profile, Skins und Server in einer schnellen, aufgeräumten Oberfläche.

01 · MODS

Modrinth direkt integriert

Finde Mods, Modpacks, Shader und Ressourcenpakete und installiere sie passend zu deiner Fabric-Version.

02 · PROFILE

Jede Version sauber getrennt

Erstelle eigene Profile mit getrennten Mods und Einstellungen, ohne Dateien von Hand verschieben zu müssen.

03 · SKINS

Dein Look vor dem Start

Importiere Skins, speichere deine Favoriten und kontrolliere dein Aussehen direkt in der Vorschau.

04 · SERVER

Schneller zusammen spielen

Speichere Server, starte Favoriten direkt und verwalte eigene Welten für deine Freunde.

05 · UPDATES

Automatisch aktuell

X Client sucht nach neuen Versionen und bereitet Updates vor, ohne deinen Spielfluss zu unterbrechen.

06 · FABRIC

Für dein Minecraft gebaut

Wähle deine Fabric-Version und lass X Client verwaltete Mods automatisch aufeinander abstimmen.
