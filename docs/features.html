Funktionen

X-Launcher

Verwalte Fabric-Versionen, Mods, Profile und Server direkt im Launcher.

Funktionen im Überblick

Modrinth integriert

Mods, Modpacks, Shader und Ressourcenpakete direkt suchen und installieren.

  • Mods, Shader und Ressourcenpakete durchsuchen
  • Modpacks über Modrinth finden
  • Inhalte passend zur Fabric-Version auswählen

Getrennte Profile

Getrennte Mods-Ordner für deine Profile. Standard-Einstellungen werden beim Start übernommen; zusätzliche Profiloptionen bleiben erhalten.

  • Separate Mods-Ordner je Profil
  • Standard-Einstellungen beim Spielstart übernehmen
  • Zusätzliche Profiloptionen behalten

Eigene Skins

Importiere eigene Skins und sieh dir deinen Look in der Vorschau an.

  • Eigene Skin-Dateien importieren
  • Look in der Skin-Vorschau prüfen
  • Skins direkt im Launcher verwalten

Server-Favoriten

Speichere Server-Favoriten und starte direkt auf deinem ausgewählten Server.

  • Server als Favoriten speichern
  • Gewählten Server direkt starten
  • Anmeldung und Server-Regeln beachten

Launcher-Updates

Die installierte Windows-Version prüft GitHub Releases. Portable Builds aktualisierst du manuell.

  • GitHub Releases als Update-Quelle
  • Updates für installierte Windows-Builds
  • Portable Builds manuell aktualisieren

Fabric-Versionen

Verwalte Fabric-Versionen und stimme verwaltete Mods auf deine ausgewählte Minecraft-Version ab.

  • Minecraft-Version für dein Profil auswählen
  • Fabric-Versionen verwalten
  • Verwaltete Mods auf Versionen abstimmen

Anmeldung

Microsoft- und Offline-Accounts.

Microsoft / Xbox

Der Launcher unterstützt die Microsoft-/Xbox-Anmeldung. Für reguläres Online-Spiel benötigst du einen Account mit Minecraft-Java-Berechtigung.

Offline-Modus mit Grenzen

Offline-Accounts sind für lokale Tests vorgesehen. Multiplayer funktioniert damit nur auf Servern im Offline-Modus.
